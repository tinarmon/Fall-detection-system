# Pre-Fall Detection 3D (ระบบประเมินความเสี่ยงและตรวจจับก่อนการล้มสไตล์ 3D)

โปรแกรมตรวจสอบและประเมินความเสี่ยงต่อการเกิดอุบัติเหตุจากการสูญเสียการทรงตัวหรือการล้มล่วงหน้าแบบเรียลไทม์ (Pre-Fall Detection) เพื่อส่งมอบสิทธิประโยชน์ความปลอดภัยสูงสุดแก่สถานที่และศูนย์ดูแลสุขภาพทั่วไป

---

## 📹 ภาพรวมการทำงานของระบบ (Program Overview)

โปรแกรมทำงานในรูปแบบหน้าต่าง Desktop Application แบบออฟไลน์ (Local Offline processing) โดยการจับพิกัดโครงร่างท่าทางของมนุษย์แบบสามมิติ (3D Skeleton tracking) และนำมาประเมินด้วยระบบโครงข่ายสมองเทียมความแม่นยำสูง เพื่อคาดการณ์ความเสี่ยงต่อการเกิดภัยล้มและทำการเตือนภัยล่วงหน้าได้ทันเวลา

---

## ✨ คุณสมบัติเด่นของโปรแกรม (Key Features)

### 1. หน้าจอตรวจจับสัญญาณภาพแบบตาราง (Live Monitoring Grid)
*   รองรับการเชื่อมต่อภาพจากกล้องหลายช่องสัญญาณพร้อมกัน (สูงสุด 4 ช่องสัญญาณกล้อง)
*   รองรับทั้งกล้องเชื่อมต่อตรงผ่านพอร์ต USB (Webcam) และลิงก์สตรีมจากกล้องวงจรปิดในระบบเครือข่าย (RTSP IP Camera)
*   จัดเก็บข้อมูลและค่าติดตั้งสตรีมกล้องทั้งหมดไว้ภายในเครื่องปลายทางอย่างปลอดภัยโดยอัตโนมัติ

### 2. ระบบแจ้งเตือนภัยแบบเรียลไทม์ (Risk Assessment HUD & Banner Alert)
*   วิเคราะห์พิกัดโครงสร้างพฤติกรรมร่างกายพร้อมแสดงเส้นโครงกระดูกแบบเรียลไทม์
*   แผงไฟแจ้งเตือนภัยสีแดงแสดงสัญญาณอันตรายกระพริบระบุกล้องตัวที่พบเหตุทันทีเมื่อค่าความเสี่ยงขึ้นสูงเกินเกณฑ์ปลอดภัย

### 3. ระบบเชื่อมต่อแจ้งเหตุผ่าน LINE Notify แบบไร้รอยต่อ (Hybrid LINE Notify)
*   ส่งคำสั่งและข้อมูลเตือนภัยล้มเข้าสู่ LINE กลุ่มที่กำหนดโดยทำงานเบื้องหลังแยกเป็นอิสระ ทำให้กล้องวิดีโอประมวลผลลื่นไหลคงที่คง FPS สูงสุด
*   **ระบบหน่วงเวลาส่งซ้ำ (Cooldown)**: ป้องกันข้อความแจ้งเตือนที่เกิดจากมุมภาพซ้ำซ้อนสแปมเข้ากลุ่มไลน์เกินความจำเป็นขณะกำลังเข้าช่วยเหลือผู้ป่วย
*   **ตั้งค่าแยกรายกล้อง (Override Token)**: สามารถกำหนดให้กล้องแต่ละจุดส่งเตือนภัยแยกเข้ากลุ่มไลน์ตามแผนกหรือตึกผู้ป่วยที่ต่างกันได้ หรือเลือกใช้ Token หลักร่วมกันเพื่อความสะดวก

### 4. ปุ่มช่วยเหลือแนะนำข้อมูลการใช้งานในตัว (Contextual Help Dialogs)
*   มีระบบปุ่มสัญลักษณ์เครื่องหมายคำถาม **`❔`** ทั่วอินเทอร์เฟสการตั้งค่า เพื่อชี้แนะวิธีกรอกรหัสแหล่งสัญญาณกล้อง วิธีการออกรหัสเชื่อมต่อ LINE Notify และคำแนะนำวิธีเข้าควบคุมโปรแกรมอย่างง่ายโดยไม่ต้องผ่านคู่มือเอกสารภายนอก
