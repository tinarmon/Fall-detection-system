# 🛡️ Pre-Fall Detection 3D (ระบบ AI เฝ้าระวังและแจ้งเตือนการล้มอัจฉริยะ)

> **ระบบตรวจจับและประเมินความเสี่ยงก่อนการล้มแบบเรียลไทม์ ด้วยเทคโนโลยี AI วิเคราะห์สรีระ 3 มิติ เชื่อมต่อกล้องไร้สายระยะไกล พร้อมส่งภาพถ่ายหลักฐานเข้า LINE ได้ทันที**

---

## 🌟 จุดเด่นและสิ่งที่เราทำได้ (What We Can Do)

ระบบ **Pre-Fall Detection 3D** ได้รับการออกแบบมาเพื่อช่วยเฝ้าระวังผู้สูงอายุ ผู้ป่วยพักฟื้น หรือบุคคลในครอบครัว เพื่อลดโอกาสเกิดอุบัติเหตุจากการสูญเสียการทรงตัว และส่งสัญญาณขอความช่วยเหลือได้อย่างทันท่วงที:

### 1. 🧠 AI วิเคราะห์สรีระและประเมินความเสี่ยงล่วงหน้า (3D AI Biomechanics)
* **ไม่ต้องสวมใส่อุปกรณ์ (Contactless)**: ผู้สูงอายุไม่ต้องกดปุ่มฉุกเฉิน ไม่ต้องพกสายรัดข้อมือหรือนาฬิกา
* **วิเคราะห์ล่วงหน้าก่อนล้ม (Pre-Fall Risk Assessment)**: AI ตรวจจับพิกัดโครงร่างร่างกายแบบ 3 มิติ (3D Skeleton Tracking) ประเมินมุมเอียงของลำตัวและความเร็วของการเคลื่อนไหว เพื่อประเมินระดับความเสี่ยงก่อนสัมผัสพื้น
* **สัญญาณไฟเตือนภัยชัดเจน (Live HUD)**: แสดงสถานะปกติ (เขียว), ระวัง (เหลือง) และล้มฉุกเฉิน (แดง) พร้อมแถบเปอร์เซ็นต์ความเสี่ยงแบบเรียลไทม์

---

### 2. 🌐 เชื่อมต่อกล้องระยะไกลผ่านเน็ตบ้านได้อย่างง่ายดาย (Remote Camera Ready)
* **ก้าวข้ามข้อจำกัดเดิม**: กล้องและคอมพิวเตอร์**ไม่จำเป็นต้องอยู่ในบ้านหลังเดียวกัน**หรือวง WiFi เดียวกันอีกต่อไป
* **รองรับกล้อง WiFi ยอดนิยม**: ใช้งานร่วมกับกล้องหมุนได้ยอดนิยมตามท้องตลาด เช่น **TP-Link Tapo C200 / C210** หรือกล้องวงจรปิด IP Camera มาตรฐาน RTSP
* **เชื่อมต่อง่ายผ่าน Tailscale**: รองรับการทำเครือข่ายส่วนตัวไร้สาย (Private Mesh Network) ดึงสัญญาณภาพจากบ้านผู้สูงอายุมายังคอมพิวเตอร์ที่สำนักงานหรืออีกบ้านหนึ่งได้ ปลอดภัย ไม่ต้องตั้งค่า Router ที่ซับซ้อน (ไม่ต้องทำ Port Forwarding)
* **ระบบปรับความเสถียรของสัญญาณภาพ (Network Resilience)**: ปรับสลับเป็นสตรีมความเร็วสูง (`/stream2`) ได้ในคลิกเดียว พร้อมระบบกู้คืนสัญญาณอัตโนมัติ (Smart Auto-Reconnect) หากเน็ตบ้านขัดข้องชั่วคราว

---

### 3. 📱 แจ้งเตือนฉุกเฉินเข้า LINE พร้อมภาพหลักฐาน 5 จังหวะ (Instant LINE Flex Alert)
* **ภาพหลักฐานลำดับเหตุการณ์**: เมื่อเกิดเหตุล้ม ระบบจะประมวลภาพถ่ายหลักฐาน 5 เฟรมต่อเนื่อง (ก่อนล้ม ➔ จังหวะล้ม ➔ หลังล้ม) ส่งเข้า LINE ทันที ช่วยให้คนในครอบครัวหรือพยาบาลประเมินสถานการณ์ได้รวดเร็วและแม่นยำ
* **การแจ้งเตือนแบบไม่ขัดจังหวะ (Non-blocking)**: ระบบส่งข้อความเบื้องหลังโดยไม่ทำให้กล้องค้างหรือกระตุก
* **ระบบป้องกันการแจ้งเตือนซ้ำ (Smart Cooldown)**: ป้องกันการส่งข้อความซ้ำซ้อนขณะกำลังเข้าช่วยเหลือ
* **บันทึกวิดีโอย้อนหลังอัตโนมัติ**: บันทึกคลิปวิดีโอช่วงเวลาเกิดเหตุเก็บไว้ในเครื่องเพื่อใช้อ้างอิงทางการแพทย์

---

### 4. 🎛️ ตรวจจับหลายห้องพร้อมกันสูงสุด 4 จุด (4-Camera Live Grid)
* สามารถเปิดมอนิเตอร์ภาพพร้อมกันได้สูงสุด 4 กล้อง (เช่น ห้องนอน, ห้องน้ำ, ห้องนั่งเล่น, บันได)
* รองรับทั้งกล้อง USB Webcam ภายในเครื่อง และกล้องไร้สาย IP Camera ประจำจุดต่างๆ
* ตั้งค่าชื่อห้องและบัญชีผู้รับแจ้งเตือนแยกแต่ละกล้องได้อย่างอิสระ

---

### 5. 🔒 ความเป็นส่วนตัวและปลอดภัยสูงสุด (100% Local AI & Privacy-First)
* ภาพเคลื่อนไหวทั้งหมดถูกวิเคราะห์อยู่บนคอมพิวเตอร์ของท่านเอง (Offline Local Processing)
* ภาพสดจากกล้องจะไม่ถูกนำไปบันทึกหรือสตรีมขึ้น Cloud สาธารณะภายนอก รักษาความเป็นส่วนตัวสูงสุดของบ้านและครอบครัว

---

## 🛠️ อุปกรณ์ที่แนะนำ (Recommended Setup)

| อุปกรณ์ | รายละเอียดที่แนะนำ |
| :--- | :--- |
| **คอมพิวเตอร์** | Windows 10 / 11 (รองรับทั้งคอมพิวเตอร์ทั่วไปและโน้ตบุ๊ก) |
| **กล้องเฝ้าระวัง** | **TP-Link Tapo C200** / C210 (กล้อง WiFi ราคาประหยัด คุณภาพสูง) หรือ Webcam ทั่วไป |
| **เครือข่าย** | สัญญาณ WiFi ประจำบ้าน หรือเชื่อมต่อทางไกลผ่านเครือข่ายส่วนตัว Tailscale |
| **ช่องทางรับแจ้งเตือน** | แอปพลิเคชัน **LINE** บนสมาร์ตโฟน |

## 🚀 3 ขั้นตอนเริ่มต้นใช้งาน (Quick Start)

### 1. เปิดโปรแกรม
เปิดโปรแกรม **Fall Detection System** ขึ้นมา หน้าจอหลักจะแสดงระบบเฝ้าระวัง 4 ช่องสัญญาณ

### 2. เพิ่มกล้องที่ต้องการ
1. คลิกที่หน้าต่างกล้องที่ต้องการใช้งาน แล้วกดปุ่ม **"⚙️ ตั้งค่ากล้อง"**
2. เลือกรูปแบบกล้อง:
   * **กล้องเสียบสาย USB (Webcam)**: เลือกหมายเลขกล้อง 0 หรือ 1 แล้วกดตกลง
   * **กล้องในบ้าน (WiFi เดียวกัน)**: กดปุ่มแม่แบบ **`[🏠 Tapo LAN]`** แล้วใส่ IP ของกล้อง
   * **กล้องระยะไกลคนละบ้าน (Tailscale)**: กดปุ่มแม่แบบ **`[🌐 Tailscale (กล้องระยะไกล)]`** แล้วใส่ IP ปลายทาง
3. กดปุ่ม **"ทดสอบสัญญาณ"** เพื่อดูตัวอย่างภาพ เมื่อสำเร็จให้กด **"บันทึก"**

### 3. เชื่อมต่อการแจ้งเตือน LINE (ง่ายใน 1 วินาที ไม่ต้องพิมพ์รหัส 33 ตัว)
1. เพิ่มเพื่อนบอท LINE OA ของระบบ (สแกน QR ในหน้าคู่มือหรือกดลิงก์)
2. เมื่อทักข้อความ บอทจะตอบกลับเป็นภาพ **QR Code** ประจำตัวคุณทันที
3. กดปุ่ม **"📷 สแกน QR"** ที่แถบด้านล่างของโปรแกรม แล้วนำหน้าจอมือถือมาจ่อหน้ากล้องคอมพิวเตอร์ ระบบจะสแกนและบันทึกรหัสให้อัตโนมัติใน 1 วินาที! *(หรือหากก๊อปปี้ข้อความมา สามารถกดปุ่ม **"📋 วางรหัส"** ระบบจะกรองรหัสให้อัตโนมัติ)*
4. กดปุ่ม **"🧪 ทดสอบส่ง"** เพื่อตรวจสอบว่าข้อความและภาพหลักฐานเข้าโทรศัพท์มือถือเรียบร้อย และเริ่มการเฝ้าระวังได้ทันที!

## 💡 คำแนะนำสำหรับการติดตั้งกล้องระยะไกล (Remote Setup Tips)

หากคุณต้องการตั้งกล้องไว้ที่บ้านผู้สูงอายุ แล้วเปิดโปรแกรมเฝ้าระวังจากที่ทำงานหรือบ้านอีกหลัง:
1. **สร้างบัญชีกล้อง (Camera Account)**: ในแอปพลิเคชัน Tapo บนมือถือ เข้าไปที่ `การตั้งค่ากล้อง` ➔ `การตั้งค่าขั้นสูง` ➔ `บัญชีกล้อง` เพื่อตั้ง Username / Password สำหรับเชื่อมต่อ
2. **ติดตั้ง Tailscale**: ติดตั้งแอป Tailscale บนอุปกรณ์ที่บ้านปลายทาง (เช่น บนคอมพิวเตอร์ หรืออุปกรณ์แชร์เครือข่าย) และบนเครื่องที่เปิดโปรแกรมนี้
3. **เลือกความเร็วที่เหมาะสม**: ในโปรแกรม ให้เลือกความละเอียดเป็นช่องสัญญาณสำรอง (**`/stream2`**) เพื่อความลื่นไหลสูงสุดของการส่งภาพผ่านเครือข่ายอินเทอร์เน็ต
