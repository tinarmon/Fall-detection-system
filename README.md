# Pre-Fall Detection 3D (Client Application Workspace)

ระบบตรวจจับท่าทางและเตือนภัยก่อนการล้มสไตล์ 3D (Pre-Fall Detection 3D) สำหรับส่งมอบให้แก่ลูกค้า (Client Distribution) โปรเจ็กต์นี้ได้รับการปรับปรุงและแยกตัวแยกออกมาทำงานเป็นเอกเทศอย่างสมบูรณ์แบบที่ตำแหน่ง **`C:\ProjectClient`** เพื่อป้องกันการสะสมไฟล์คอมไพล์ไบนารีส่วนเกินบน Git ประวัติการพัฒนาหลัก

## 🚨 ระบบแจ้งเตือน LINE Notify แบบผสม (Hybrid LINE Notify)

ระบบรองรับการส่งข้อความแจ้งภัยล้มเข้าสู่กลุ่มแชต LINE โดยทำงานผ่านเธรดเบื้องหลังแยกเฉพาะ (Asynchronous Daemon Thread) เพื่อคงความเร็วการสตรีมประมวลผลไว้ที่ **30 FPS ลื่นไหลคงที่** ไร้อาการสะดุดหรือหน้าจอดับ:

1.  **Global LINE Token (Token หลักของแอป)**: กรอกได้ทันทีที่ช่องตั้งค่าล่างสุดของหน้าจอหลัก โปรแกรมจะใช้ Token นี้ส่งคำสั่งเตือนของทุกกล้องเข้าห้องแชตไลน์เดียวกันเป็นหลัก
2.  **Camera Specific Token (Token แยกรายกล้อง)**: เข้าไปที่ไอคอนฟันเฟือง (⚙️) บนขอบภาพกล้องแต่ละแชนแนล เพื่อระบุ Token เจาะจงสำหรับส่งแจ้งเตือนกล้องห้องนั้น ๆ แยกกลุ่มออกไป (หากปล่อยว่าง ระบบจะสลับไปดึง Token หลักมาใช้แทน)
3.  **ระบบทดสอบส่ง (🧪 Test Send)**: สามารถกดทดสอบยิงข้อความเข้าห้อง LINE เพื่อทดสอบความเสถียรของ Token และเครือข่ายก่อนใช้งานจริง
4.  **ระบบหน่วงเวลา (60s Cooldown)**: โปรแกรมจะบล็อกการยิงการเตือนซ้ำของกล้องเดิมเป็นเวลา 60 วินาที เพื่อหลีกเลี่ยงข้อความสแปมรัวในห้องแชตไลน์ขณะเจ้าหน้าที่เข้าช่วยเหลือผู้ป่วย

## ❔ ปุ่มช่วยเหลือการใช้งานในตัว (Contextual Help Dialogs)

เพิ่มปุ่มนำทางและคำแนะนำสัญลักษณ์ **`❔`** ทั่วระบบเพื่อให้ลูกค้าตั้งค่าได้ด้วยตัวเองโดยไม่สับสน:
*   **❔ บนหัวแถบจอหลัก**: อธิบายข้อควรทราบระบบและความปลอดภัยของตัวติดตั้ง DPDF
*   **❔ ข้าง Camera Source**: อธิบายความแตกต่างระหว่างกล้องเว็บแคมพอร์ต USB (ใส่เลข `0`, `1`) และกล้องวงจรปิด IP Camera (ใส่ลิงก์สตรีม `rtsp://...`)
*   **❔ ข้างช่อง LINE Token**: แนะนำคู่มือการล็อกอินออกรหัส Token จากเว็บ `notify-bot.line.me` อย่างเป็นขั้นตอน

## 📦 วิธีการคอมไพล์เป็นไฟล์ติดตั้งเดี่ยว (`DPDF_Setup.exe`)

เราเปลี่ยนการบิวด์มาใช้รูปแบบ **PyInstaller Standalone Bytecode (Onedir)** ซ่อนซอร์สโค้ดดิบ `.py` ทั้งหมดลงเป็นไบนารี `.pyc` ภายใน ทำให้ปกป้องโค้ดได้เหมือนโปรแกรมทั่วไป และลดขนาดตัวติดตั้งลงเหลือเพียง **~270 MB** (จากเดิม 527 MB)

หากต้องการบิวด์ตัวติดตั้งใหม่ ให้เปิด PowerShell แล้วรันคำสั่งนี้:
```powershell
& "C:\Project\venv\Scripts\python.exe" "C:\ProjectClient\build_client.py"
```

หลังบิวด์สำเร็จ ไฟล์ดาวน์โหลดติดตั้งจะถูกสร้างขึ้นทันทีที่โฟลเดอร์:
📁 **`C:\ProjectClient\for client\DPDF_Setup.exe`**
