# Pre-Fall Detection System using MediaPipe and GRU (Refactored Version)

ระบบตรวจจับสภาวะการเสียการทรงตัว (Pre-fall) แบบเรียลไทม์ โดยใช้การวิเคราะห์โครงร่างมนุษย์ (Skeleton-based) และคำนวณมุมข้อต่อร่วมกับการประมวลผลเชิงเวลาด้วยโมเดล **Gated Recurrent Unit (GRU)**

โปรเจ็กต์นี้ได้รับการปรับปรุงและรวบรวมเข้าด้วยกันเป็นแอปพลิเคชันแบบเมนูสั่งการ (Menu-driven CLI Application) ที่ใช้งานง่ายและทนทานบน Windows ด้วยระบบติดตั้งและรันในคลิกเดียว

---

## 🐍 เวอร์ชันของ Python ที่แนะนำ (Recommended Python Version)

* **แนะนำเป็นอย่างยิ่ง: Python 3.10 (64-bit)**
* **เหตุผล**: ระบบประมวลผลการคำนวณหลักใช้งาน **TensorFlow (v2.21.0)** และ **MediaPipe (v0.10.33)** ซึ่งมีความเสถียรและมีไฟล์ติดตั้งสำเร็จรูป (Pre-compiled Wheels) รองรับ Windows บน Python เวอร์ชัน 3.10 มากที่สุด การใช้ Python เวอร์ชันที่ใหม่เกินไป (เช่น 3.11 หรือ 3.12+) หรือเก่าเกินไป อาจทำให้ติดตั้ง TensorFlow หรือ MediaPipe ไม่ผ่านหรือมีปัญหาเรื่องความเข้ากันได้

## 🎮 รายละเอียดเมนูการทำงานหลัก (main.py)

เมื่อเปิดใช้งานโปรแกรมผ่าน `run.bat` คุณจะพบตัวเลือกเมนูดังนี้:

### [1] เก็บข้อมูลการเคลื่อนไหว (Data Acquisition)
ระบบจัดการเก็บข้อมูลพิกัดและองศาข้อต่อแบบแยกเป็นรายเซสชัน:
* **Subject ID**: ระบบจะตรวจสอบตัวอักษรของชื่อผู้ทดสอบ เพื่อความปลอดภัยในการบันทึกไฟล์ลงดิสก์
* **แหล่งข้อมูล**: สามารถเลือกเก็บข้อมูลจาก `[1] กล้อง Webcam` หรือ `[2] ไฟล์วิดีโอในเครื่อง` (สำหรับวิดีโอ สามารถลากไฟล์มาวางในคอมมานด์ไลน์เพื่อใช้งานได้ทันที)
* **การบันทึกข้อมูล**: 
  - ข้อมูลจะบันทึกเป็นไฟล์เซสชันอิสระภายใต้โฟลเดอร์ `data/raw/session_{Subject_ID}_{Timestamp}.csv`
  - ทำการจัดเก็บข้อมูลผ่าน **Atomic memory buffer** ในแรม และจะบันทึกเขียนไฟล์ลงดิสก์เมื่อผู้ใช้ออกจากโปรแกรมอย่างสะอาดเท่านั้น
  - ในโหมดวิดีโอ ระบบจะให้เลือกป้ายกำกับ (0 = ท่าปกติ, 1 = ท่าล้ม) ล่วงหน้าและกำหนดให้กับเฟรมทั้งหมดโดยอัตโนมัติ
  - ในโหมดกล้อง สามารถกดคีย์บอร์ด `n` (บันทึกปกติ), `f` (บันทึกท่าล้ม), `p` / `Spacebar` (หยุดชั่วคราว), `q` / `Esc` (ออกและบันทึกผล)

### [2] วิเคราะห์ข้อมูลสถิติฟีเจอร์ (Feature Engineering)
ระบบจะสแกนและดึงไฟล์ข้อมูลเซสชันจากโฟลเดอร์เก็บข้อมูล (จะใช้ข้อมูลที่ผ่านการคลีนใน `data/clean/` ก่อนเป็นอันดับแรก หากไม่พบจะใช้ข้อมูลดิบใน `data/raw/`) มารวมกันเพื่อวิเคราะห์ค่าสถิติเฉลี่ย (Mean) และส่วนเบี่ยงเบนมาตรฐาน (Std) ของมุมข้อต่อและพิกัดสำคัญ เพื่อหาตัวแปรที่สามารถบ่งชี้ท่าล้มได้มีนัยสำคัญที่สุด โดยจะสร้างสรุปออกมาที่ไฟล์ `data/feature_statistics_report.csv`

### [3] ฝึกสอนโมเดลสมองเทียม AI (Model Training)
ใช้ข้อมูลเซสชันทั้งหมด (ดึงจาก `data/clean/` เป็นหลักและ fallback ไปที่ `data/raw/` หากยังไม่ได้ทำความสะอาด) มาผ่านขั้นตอน **Data Preprocessing & Sequence Creation** (ประกอบข้อมูล 10 เฟรมต่อเนื่องย้อนหลัง) ป้อนเข้าสอนโครงข่ายประสาทเทียมแบบ **GRU 2 ชั้น** โดยจะประเมินประสิทธิภาพกับ Validation Set และเซฟเป็นไฟล์โมเดลไปที่ `assets/fall_model.keras`

### [4] ตรวจจับความเสี่ยงแบบเรียลไทม์ (Real-time Tracking)
ดึงโมเดลโมเดล GRU ที่ฝึกสอนล่าสุดและโมเดลตรวจจับจุดสำคัญ (MediaPipe) มารันการทำนายผลเรียลไทม์จากกล้อง Webcam พร้อมประมวลผลการเคลื่อนไหวและแสดงผลแถบแจ้งเตือนระดับความเสี่ยง (Risk Bar) ทันทีหากความน่าจะเป็นสูงกว่าขีดจำกัดที่ตั้งไว้ (ตั้งค่าได้ใน `config.py`)

### [5] ตรวจสอบสถานะระบบ (Metadata Diagnostics)
รันเพื่อตรวจสอบไฟล์ที่จำเป็นในระบบ (เช็คโมเดล `fall_model.keras`, โมเดลโครงร่างของ MediaPipe รวมถึงเช็คจำนวนข้อมูลดิบใน `data/raw/` และข้อมูลที่ผ่านการทำความสะอาดใน `data/clean/`) เพื่อเช็คความพร้อมก่อนเปิดใช้งานจริง

### [6] ทำความสะอาดและปรับปรุงข้อมูลดิบ (Clean & Normalize Data)
ใช้ระบบตรวจจับการเคลื่อนไหวที่ผิดพลาดเชิงโครงสร้างแนวนอน (Tracking Swaps) เพื่อค้นหาช่วงของเฟรมที่ MediaPipe ล็อคเป้าหมายคนข้างหลังโดยไม่ได้ตั้งใจ (0-30 เฟรม) และนำมาผ่านกระบวนการทำความสะอาดข้อมูลด้วยวิธี **Linear Interpolation** ร่วมกับ **Edge-holding** ทำให้เฟรมของข้อมูลยังคงเดิมแต่พิกัดเป้าหมายและมุมเคลื่อนไหวถูกต้องอย่างสมบูรณ์แบบ ก่อนนำข้อมูลไปวิเคราะห์ฟีเจอร์หรือฝึกสอนโมเดล

## ⚙️ การกำหนดค่าเพิ่มเติม (config.py)

คุณสามารถปรับแต่งค่าต่างๆ ได้ที่ไฟล์ [config.py](file:///c:/Project/config.py) เช่น:
* `TIME_STEPS`: จำนวนเฟรมที่โมเดลมองย้อนหลังเพื่อวิเคราะห์ลำดับเหตุการณ์ (ค่าเริ่มต้น: 10 เฟรม)
* `FALL_THRESHOLD`: เกณฑ์ความน่าจะเป็นในการแจ้งเตือนสภาวะเสียการทรงตัว (ค่าเริ่มต้น: 0.6)
* `TARGET_LANDMARKS`: ลำดับจุดบนร่างกายของ MediaPipe ที่ประสงค์ใช้ประมวลผล
* `JUMP_THRESHOLD`: ค่าเกณฑ์ความสูงของการเคลื่อนไหวแนวนอนเพื่อตรวจจับ subject สลับ
* `OUTLIER_DISTANCE_THRESHOLD`: ค่าเกณฑ์ระยะห่างขอบเขตแนวนอนสะโพกกับแกน Median เพื่อตัดสิน outlier
